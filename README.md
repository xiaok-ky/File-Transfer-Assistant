# 传输助手

局域网内的文件与文字传输工具 —— 用来替代微信「文件传输助手」，
**不用扫码登录，没有文件大小限制**，电脑和手机在同一个网络下就能互传。

---

## 它解决什么问题

| 微信文件传输助手 | 传输助手 |
|---|---|
| 每次都要扫码登录 | **打开就能用**，地址固定 |
| 文件有大小限制 | **没有限制**（10GB 的电影也能传） |
| 文件要先上传到微信服务器 | **局域网直连**，不出本机网络 |
| 下载慢 | 取决于你的 WiFi（1000m家用宽带测试速度40m/s） |

---

## 功能

- **文字双向传输** —— 手机 ↔ 电脑，两边都能选中复制
- **手机一键送进电脑剪贴板** —— 复制完直接在电脑 Ctrl+V
- **文件互传** —— 手机上传 / 电脑发送，图片 PDF 可直接预览
- **不复制文件** —— 电脑发文件给手机时只登记路径，零额外硬盘占用
- **断点续传** —— 关掉软件再打开，「继续未完成」接着传
- **传输控制** —— 中止 / 暂停 / 中止并删除源文件
- **多连接并行** —— 大文件自动分片，最多 8 个连接
- **多人隔离** —— 同一台电脑不同 Windows 账号，数据、端口、网址互不干扰

## 快速开始

### 直接用（推荐给普通用户）

1. 下载 `传输助手-v1.0.zip`，解压
2. 双击 `传输助手.exe`（首次运行 Windows 会弹防火墙提示，点「允许」）
3. 手机扫窗口右上角的二维码
4. 第一次打开点「我是新设备」，建议「添加到主屏幕」

### 从源码运行

```bash
pip install qrcode
python wifi_gui.py
```

只需要标准库 + `qrcode`（纯 Python，用于生成二维码矩阵）。

### 自己打包

```bash
pip install pyinstaller qrcode
pyinstaller --clean --noconfirm wifi_gui.spec
```

产物在 `dist_gui/传输助手/`。

## 工作原理

```
┌────────────┐   同一个 WiFi    ┌──────────────────────┐
│ 手机浏览器  │ ←─────────────→ │ 传输助手.exe          │
└────────────┘   HTTP + Token   │ ThreadingHTTPServer  │
                                └──────────────────────┘
```

- 电脑起一个 HTTP 服务（默认端口 8765）
- 手机浏览器访问 `http://<电脑IP>:8765/<token>/`
- **token 是首次运行时随机生成的**，存在 `data/<用户名>/token.txt`，决定访问网址
- 设备用 16 位十六进制 ID 区分，cookie + 请求头双重识别
- 文件索引存 SQLite（WAL 模式），每个设备一个库
- 大文件走 `p2p-begin` / `p2p-part` / `p2p-end` 三段式并行传输

## 目录结构

```
传输助手/
├── wifi_core.py        # 后端全部逻辑（HTTP 服务、存储、传输、剪贴板、二维码）
├── wifi_gui.py         # tkinter 界面
├── wifi_gui.spec       # PyInstaller 打包配置
├── 使用说明.md          # 给普通用户的说明
└── data/<用户名>/      # 运行时生成（**不在仓库里**）
    ├── 文件/           # 手机上传的文件
    ├── resume/         # 断点续传记录
    ├── token.txt       # 访问密钥
    ├── pcid.txt        # 本机编号
    ├── devices/        # 每台设备的记录数据库
    └── error.log       # 出错日志
```

## 已知限制

- **电脑端只支持 Windows**（用了 `ctypes` 调 Win32 剪贴板、`explorer /select`）
- 手机端是网页，**不需要装 App**
- 传输走局域网**明文 HTTP**，token 在 URL 里。**适合信任的家庭/办公 WiFi，不要在公共网络传敏感信息**
- 手机浏览器对文件名支持不一致，少数 ROM 会把下载的文件改名
- 无 TLS、无密码学加密（设计上是「同一 WiFi 下的便利优先」）

---

## 数据与隐私

**你的数据只在两种地方：**

1. `data/<用户名>/` —— 本机目录，包含记录和 token
2. 传输过程中经过局域网（不经过任何服务器）

**没有遥测、没有联网上报、不依赖任何云服务。**
